# Curso de Bootstrap do Zero

Mesmo formato das outras trilhas. Bootstrap é um **framework CSS**: uma biblioteca de estilos e componentes prontos, construída em cima de tudo que você aprendeu em [[../CSS/00-Indice]] — só faz sentido de verdade depois de entender CSS puro, porque Bootstrap é, no fundo, um conjunto enorme de classes CSS já escritas para você, aplicando os mesmos conceitos (Flexbox, Grid, media queries) por trás.

> **Nota sobre os exemplos**: os exemplos usam Bootstrap via **CDN** (um link direto para os arquivos, sem precisar instalar nada) — basta ter internet para abrir os `.html` de exemplo no navegador.

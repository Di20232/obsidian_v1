# DRE simplificada

A **DRE** (Demonstração do Resultado do Exercício) mostra, no regime de [[02-Regime-de-Caixa-e-Competencia|competência]], se a empresa deu lucro num período e **em que degrau** o dinheiro ficou pelo caminho. A contabilidade faz a DRE oficial; uma versão gerencial simples, feita por você todo mês, já muda as decisões.

## A escada da DRE, com um mês de exemplo

| Linha | Valor | Como se calcula |
|---|---|---|
| **Receita bruta** | R$ 50.000 | tudo que foi vendido no mês |
| (−) Impostos sobre vendas | R$ 2.660 | alíquota efetiva do Simples, 5,32% neste exemplo ([[10-Impostos-MEI-Simples-e-Reforma\|cálculo]]) |
| (−) Devoluções e cancelamentos | R$ 1.000 | |
| **= Receita líquida** | **R$ 46.340** | |
| (−) CMV (custo da mercadoria vendida) | R$ 22.000 | custo só do que foi vendido, não de tudo que foi comprado |
| **= Lucro bruto** | **R$ 24.340** | |
| (−) Despesas variáveis | R$ 8.300 | taxas de cartão R$ 1.800 + frete R$ 2.500 + marketing R$ 4.000 |
| **= Margem de contribuição** | **R$ 16.040** (32,1%) | o que sobra para pagar a estrutura |
| (−) Despesas fixas | R$ 11.000 | aluguel, pró-labore, salários, contador, sistemas |
| **= Lucro operacional** | **R$ 5.040** | |
| (−) Despesas financeiras (juros) | — | |
| **= Lucro líquido** | **R$ 5.040** | **margem líquida de 10,1%** |

No Simples Nacional, o imposto sobre o lucro já está dentro do DAS, na linha de impostos sobre vendas. Em outros regimes existe uma linha de IR e CSLL antes do lucro líquido.

## CMV não é compra do mês

O **CMV** é o custo das mercadorias que **saíram** vendidas no mês:

```text
CMV = estoque inicial + compras do mês − estoque final
```

Comprar R$ 40.000 de estoque para o Natal em outubro não faz outubro ter prejuízo: o custo entra quando a mercadoria é vendida. Essa diferença é o que separa a DRE do [[03-Fluxo-de-Caixa|fluxo de caixa]], onde a compra de outubro sai em outubro (ou no vencimento do boleto).

## Como ler a DRE

| Se isto está ruim | Olhe primeiro |
|---|---|
| **Lucro bruto** baixo | preço baixo demais ou custo de compra alto: renegociar fornecedor, rever [[06-Formacao-de-Preco\|preço]] |
| **Margem de contribuição** baixa | taxas, frete e marketing comendo a margem: ver [[Ecommerce/02-Planejamento-e-Precificacao\|a conta completa de uma venda]] |
| **Lucro operacional** baixo com margem boa | estrutura fixa pesada para o volume de vendas: ver [[05-Custos-Margem-e-Ponto-de-Equilibrio\|ponto de equilíbrio]] |
| Lucro líquido muito abaixo do operacional | juros de dívidas: ver [[11-Credito-Juros-e-Emprestimos\|crédito]] |

Compare cada linha em **porcentagem da receita** mês a mês. Os valores em reais mudam com a sazonalidade; as porcentagens mostram o que piorou de fato.

## Perguntas de revisão

O que é a DRE? :: A Demonstração do Resultado do Exercício, que mostra no regime de competência se a empresa deu lucro no período e onde o dinheiro ficou.

Qual a sequência principal da DRE? :: Receita bruta, menos impostos e devoluções, receita líquida, menos CMV, lucro bruto, menos despesas variáveis, margem de contribuição, menos despesas fixas, lucro operacional, e lucro líquido.

Como se calcula o CMV? :: Estoque inicial mais compras do período menos estoque final.

Comprar muito estoque num mês gera prejuízo na DRE daquele mês? :: Não; o custo entra no CMV só quando a mercadoria é vendida.

Por que comparar as linhas da DRE em porcentagem da receita? :: Porque os valores em reais variam com a sazonalidade, e as porcentagens mostram o que realmente piorou.

Se o lucro bruto está baixo, o que revisar primeiro? :: O preço de venda e o custo de compra da mercadoria.

# Próximos Passos e Trilhas

## Onde você está agora

Depois do [[../Python/00-Indice|curso de Python]] e desta trilha geral, você tem: uma linguagem de programação funcional, entendimento de estruturas de dados e algoritmos, noção de como a web e bancos de dados funcionam, um panorama de outras linguagens, e hábitos de qualidade (testes, boas práticas, Git). Isso é mais base do que muita gente tem ao começar a trabalhar profissionalmente com código. O próximo passo natural não é "aprender mais teoria" — é **construir coisas reais** e, a partir daí, se especializar.

## Áreas de especialização (visão geral)

### Desenvolvimento Web
- **Front-end**: HTML/CSS/JavaScript ([[07-HTML-e-CSS]], [[08-JavaScript-Basico]]) + frameworks como React, Vue ou Svelte.
- **Back-end**: lógica de servidor, bancos de dados ([[09-SQL-e-Bancos-de-Dados]]), APIs ([[10-Como-a-Web-Funciona]]) — em Python, os frameworks mais usados são Flask (mais simples/flexível) e Django (mais completo, "pilhas incluídas").
- **Full-stack**: as duas pontas juntas.

### Dados e Inteligência Artificial
- **Análise de dados**: usa fortemente Python com `pandas` (tabelas de dados) e `matplotlib`/outras (visualização).
- **Ciência de dados / Machine Learning**: estatística aplicada, `scikit-learn`, `pytorch`/`tensorflow` para modelos mais avançados.
- Python é, hoje, a linguagem dominante nessa área — o que você já aprendeu é diretamente a base necessária.

### Automação e Scripts
- Automatizar tarefas repetitivas (planilhas, arquivos, web scraping, integração entre sistemas). É frequentemente o uso mais imediatamente aplicável do que você já aprendeu neste cofre, sem precisar de nenhum conhecimento novo de peso.

### Sistemas e Infraestrutura
- Redes, servidores, DevOps (automatizar deploy e operação de sistemas), Cloud (AWS, GCP, Azure). Costuma envolver Linux, terminal ([[02-Terminal-e-Linha-de-Comando]]) e scripts intensamente.

### Desenvolvimento Mobile
- Apps nativos: Kotlin (Android) ou Swift (iOS).
- Multiplataforma: React Native, Flutter — um único código-base rodando nos dois sistemas.

### Jogos
- C++ e C# (com a engine Unity) dominam essa área; Python também é usado para prototipagem rápida.

### Sistemas de baixo nível
- Sistemas operacionais, drivers, sistemas embarcados — domínio de C/C++/Rust ([[11-C-e-Memoria]]).

## Como escolher

Não escolha por "o que paga mais" isoladamente — escolha por **o que te dá vontade de abrir o editor de código de novo amanhã**. Curiosidade sustentada importa mais, no longo prazo, do que a área "certa" no papel. Se você não tem certeza, o caminho mais barato é experimentar um projeto pequeno em 2-3 áreas diferentes antes de se aprofundar em uma.

## Como praticar de forma que realmente gruda

1. **Construa projetos pequenos e completos**, não só exercícios soltos — algo com começo, meio e fim que você mesmo queira usar (um controle de gastos pessoal, um bot simples, um scraper de preços).
2. **Leia código de outras pessoas** — projetos open source no GitHub na sua área de interesse. Você aprende padrões que nenhum curso ensina isoladamente.
3. **Explique o que você aprendeu para outra pessoa** (ou escreva sobre isso) — é a forma mais eficaz de descobrir o que você ainda não entendeu de verdade.
4. **Contribua com algo real**, mesmo pequeno — corrigir um erro de digitação na documentação de um projeto open source já ensina o fluxo de Pull Request de [[03-Git-e-Controle-de-Versao]].

## Recursos para continuar (gratuitos e amplamente usados)

- Documentação oficial do Python: `docs.python.org/pt-br` (tem versão em português).
- `developer.mozilla.org` (MDN) — a referência mais confiável de HTML, CSS e JavaScript.
- `github.com` — para explorar projetos reais e praticar Git na prática.
- Comunidades: fóruns e comunidades de Python em português, Stack Overflow para dúvidas específicas de erro.

## Uma última coisa

A sensação de "não saber nada" nunca desaparece completamente — ela só muda de assunto conforme você avança. Isso não é sinal de que você está atrasado, é a natureza normal de uma área que muda e se expande constantemente. O objetivo não é saber tudo; é ter base sólida o suficiente (que você já tem, depois destas duas trilhas) para aprender o resto conforme for precisando.

# Conhecimento Geral de Programação

Esta trilha complementa os cursos de linguagem e tecnologia deste cofre: [[../Python/00-Indice|Python]], [[../JavaScript/00-Indice|JavaScript]], [[../PHP/00-Indice|PHP]], [[../MySQL/00-Indice|MySQL]], [[../SQLite/00-Indice|SQLite]], [[../CSS/00-Indice|CSS]], [[../Bootstrap/00-Indice|Bootstrap]] e [[../TailwindCSS/00-Indice|TailwindCSS]]. Lá você aprende **a usar** cada ferramenta especificamente. Aqui o foco é diferente: conceitos que valem para **qualquer** linguagem, um panorama de outras linguagens importantes, e as peças que formam o mundo do desenvolvimento de software fora do próprio código (terminal, versionamento, web, bancos de dados, memória, testes).

A ideia é que, depois desta trilha, você entenda não só "como escrever um `if`", mas **como o ecossistema inteiro de programação se encaixa** — o suficiente para conversar com outro programador, escolher a ferramenta certa para um problema, e saber por onde procurar quando precisar aprender algo novo.

## Como usar esta trilha

Você não precisa "programar em C" ou "dominar SQL" depois de ler as notas 07-11 — o objetivo é **reconhecimento**: entender o que cada tecnologia faz, por que ela existe, e ler um trecho de código dela sem se perder. Aprofundamento de verdade vem com prática, projeto real e tempo — esta trilha é o mapa, não o território.

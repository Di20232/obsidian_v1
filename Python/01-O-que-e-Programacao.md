# O que é Programação

## O problema que isso resolve

Um computador só sabe fazer uma coisa: seguir instruções, exatamente como foram escritas, em ordem. Ele não tem intuição nem "entende" o que você quer — ele executa. **Programar é escrever essas instruções** de um jeito que o computador consiga seguir sem ambiguidade.

Pense em uma receita de bolo escrita para alguém que só faz exatamente o que está escrito, sem interpretar nada: "misture os ingredientes" não funciona, porque "misture" é vago. Você precisa dizer "pegue a farinha, coloque na tigela, pegue o ovo, quebre na tigela, mexa por 2 minutos". Programar é isso, em outro idioma.

## O que é uma linguagem de programação

Computadores, no fundo, só entendem sequências de 0 e 1 (código binário). Ninguém escreve programas grandes assim — seria inviável. Por isso existem **linguagens de programação**: um conjunto de palavras e regras (uma sintaxe) que humanos conseguem ler e escrever, e que depois é traduzido para o que o computador realmente executa.

Existem centenas de linguagens (Python, JavaScript, C, Java...). Cada uma tem prioridades diferentes: algumas priorizam velocidade, outras facilidade de leitura, outras controle detalhado do hardware.

## Por que Python

Python foi desenhado para ser **lido quase como inglês simples** e para que o código de uma pessoa seja fácil de outra pessoa entender depois. Isso o torna uma ótima primeira linguagem porque você gasta menos energia decorando símbolos e mais energia entendendo lógica — que é a parte que realmente importa e se transfere para qualquer outra linguagem depois.

Python é usado em: automação de tarefas, análise de dados, ciência de dados e IA, desenvolvimento web (back-end), scripts de sistema, testes automatizados, entre outros.

## Compilado vs. interpretado (o essencial)

Algumas linguagens são **compiladas**: existe uma etapa que traduz todo o código para linguagem de máquina antes de rodar, gerando um arquivo executável.

Python é **interpretado**: existe um programa chamado **interpretador** que lê seu código linha a linha e vai executando na hora. É por isso que, mais adiante, você vai rodar arquivos `.py` chamando o programa `python`, em vez de gerar um `.exe` separado.

## Vocabulário que você vai ver sempre

- **Código-fonte**: o texto que você escreve, em arquivos `.py`.
- **Interpretador**: o programa que lê e executa seu código Python.
- **Sintaxe**: as regras de como escrever corretamente (tipo a gramática da linguagem).
- **Erro de sintaxe**: quando você escreve algo que quebra essas regras — o interpretador nem chega a tentar rodar.
- **Bug**: um erro de lógica — o código roda, mas faz a coisa errada.
- **Executar / rodar**: mandar o interpretador processar seu arquivo.

## Exercício

Sem escrever código ainda: pense em uma tarefa do seu dia a dia (por exemplo, "separar e-mails importantes") e escreva, em português, passo a passo, tão detalhado que uma pessoa sem contexto nenhum conseguiria seguir sem perguntar nada. Isso é pensar como um programador.

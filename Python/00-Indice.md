# Curso de Python do Zero

Este é o ponto de partida. A ideia é simples: você não precisa saber **nada** de programação para começar. Cada nota explica um conceito, o **porquê** ele existe (qual problema ele resolve), e a **sintaxe correta** com exemplos comentados.

Siga na ordem abaixo. Não pule etapas — em programação, cada conceito novo se apoia nos anteriores.

## Trilha

1. [[01-O-que-e-Programacao]] — o que é programar, o que é uma linguagem, o que é o Python
2. [[02-Instalando-Python]] — preparar o computador para rodar código
3. [[03-Primeiro-Programa]] — "Olá, mundo" e como o Python executa um arquivo
4. [[04-Variaveis-e-Tipos]] — guardar e nomear informação
5. [[05-Operadores]] — fazer contas e comparações
6. [[06-Entrada-e-Saida]] — conversar com quem usa o programa
7. [[07-Condicionais]] — tomar decisões (`if`)
8. [[08-Lacos-de-Repeticao]] — repetir tarefas (`for`, `while`)
9. [[09-Listas-Tuplas-Dicionarios]] — guardar várias informações juntas
10. [[10-Strings]] — manipular texto de verdade
11. [[11-Funcoes]] — organizar código em blocos reutilizáveis
12. [[12-Modulos-e-Pacotes]] — usar código de terceiros e organizar o seu
13. [[13-Tratamento-de-Erros]] — lidar com o que dá errado
14. [[14-Arquivos]] — ler e salvar dados em disco
15. [[15-Programacao-Orientada-a-Objetos]] — modelar problemas com classes e objetos
16. [[16-Boas-Praticas-e-Proximos-Passos]] — como continuar depois deste curso

## Exemplos executáveis

Cada nota tem um arquivo correspondente em `Python/exemplos/`, com código pronto para rodar. Sempre que puder, **rode o exemplo você mesmo** e depois altere algo nele — é assim que o conhecimento gruda.

## Como estudar cada nota

1. Leia o "por quê" antes do "como" — entender o motivo evita decorar sintaxe sem sentido.
2. Digite os exemplos à mão em vez de copiar e colar, pelo menos na primeira vez.
3. Faça o exercício no fim de cada nota antes de seguir para a próxima.
4. Erros vão acontecer o tempo todo — isso é normal e faz parte do processo, não é sinal de que você "não é bom nisso".

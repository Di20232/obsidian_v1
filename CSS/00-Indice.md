# Curso de CSS do Zero (Avançado)

A introdução a CSS já existe em [[../Programacao-Geral/07-HTML-e-CSS]] — seletores básicos, propriedades essenciais, a ideia de separar estrutura (HTML) de aparência (CSS). Esta trilha **aprofunda** cada peça daquela introdução, no mesmo formato das outras: conceito, porquê, sintaxe correta, exercício.

> **Nota sobre os exemplos**: cada nota tem um `.html` autocontido em `CSS/exemplos/` — abra direto no navegador (duplo clique, ou arraste para uma aba) para ver o resultado, sem precisar de servidor nenhum.

## Trilha

1. [[01-Seletores-e-Especificidade]] — indo além de tag/classe/id: combinadores, pseudo-classes, e por que duas regras conflitantes escolhem uma
2. [[02-Box-Model]] — como o navegador calcula o tamanho de cada elemento
3. [[03-Cores-Unidades-e-Tipografia]] — `px` vs `rem`, `hex` vs `rgb`, controlando texto
4. [[04-Flexbox]] — alinhando e distribuindo elementos em uma linha ou coluna
5. [[05-Grid]] — layouts bidimensionais de verdade
6. [[06-Posicionamento]] — `static`, `relative`, `absolute`, `fixed`, `sticky`
7. [[07-Responsividade]] — uma página que funciona do celular ao monitor grande
8. [[08-Transicoes-e-Animacoes]] — movimento sem JavaScript
9. [[09-Boas-Praticas-e-Proximos-Passos]] — organização de CSS em projetos reais, e para onde ir depois

# 🧱 Modelos de Nota

Insira o modelo adequado ao criar uma nova nota (`Ctrl+P` → *Modelos: Inserir modelo*; esta pasta já é a pasta de modelos do Obsidian). Ajuste o que não se aplicar: modelos servem para reduzir esquecimento, não para criar burocracia.

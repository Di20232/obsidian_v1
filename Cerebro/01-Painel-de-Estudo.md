# 📚 Painel de Estudo

Use este painel para escolher **uma prioridade por vez**, manter o ritmo e registrar evidências de que aprendeu — não só páginas lidas.

## Trilhas disponíveis

| Prioridade | Trilha | Resultado prático |
|---|---|---|
| Base | [[../Programacao-Geral/00-Indice|Programação Geral]] | explicar como software, web e dados se conectam |
| Linguagem | [[../Python/00-Indice|Python]] ou [[../JavaScript/00-Indice|JavaScript]] | construir pequenos programas sem copiar tudo |
| Interface | [[../CSS/00-Indice|CSS]] + [[../Bootstrap/00-Indice|Bootstrap]] ou [[../TailwindCSS/00-Indice|Tailwind CSS]] | criar telas responsivas |
| Banco de dados | [[../SQLite/00-Indice|SQLite]] ou [[../MySQL/00-Indice|MySQL]] | modelar, consultar e alterar dados com segurança |
| Servidor | [[../PHP/00-Indice|PHP]] | lidar com formulários, regras e dados no back-end |

## Sessão de estudo de 45–90 minutos

1. Escolha uma única nota ou exercício.
2. Antes de ler, escreva uma pergunta: “o que isto resolve?”.
3. Estude e reproduza o exemplo com as próprias mãos.
4. Modifique o exemplo para criar uma variação sua.
5. Registre na [[Inbox/00-Capturar|Caixa de Captura]]: conceito, exemplo e dúvida restante.
6. Ao fim da semana, transforme as melhores capturas em notas permanentes.

## Revisão semanal

- [ ] Abri os links das notas criadas nesta semana?
- [ ] Consigo explicar os conceitos sem consultar o texto?
- [ ] Tenho um exemplo executável ou um pequeno projeto?
- [ ] Uma dúvida virou tarefa concreta de pesquisa ou prática?
- [ ] Conectei a nota a um mapa ou projeto?

## O que foi preservado

São **498 arquivos de origem**, com 90 documentos Markdown. Cada arquivo tem uma nota consultável, indicação de origem e commit. Os cinco binários têm fichas e ficam íntegros nos ZIPs; o restante está legível dentro das notas.

Os ZIPs guardam os arquivos originais da branch principal no commit indicado, incluindo código, documentação, exemplos, configurações, testes e licença. As notas derivadas recebem propriedades e links para navegação. Não é uma sincronização contínua nem uma cópia do histórico completo de commits, issues ou pull requests.

# 🧩 Mapa de Programação

Programar é transformar uma necessidade em instruções claras, testáveis e mantíveis. A linguagem muda; estes pilares se repetem.

```text
Problema → dados → algoritmo → código → teste → entrega → aprendizado
```

## Habilidades que acompanham qualquer linguagem

- decompor um problema em passos pequenos;
- ler mensagens de erro e formular hipóteses;
- pesquisar documentação oficial;
- usar Git para criar um histórico seguro;
- escrever testes para comportamentos importantes;
- comunicar decisões e limitações;
- revisar e simplificar código depois de fazê-lo funcionar.

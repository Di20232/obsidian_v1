# Definição de pronto

Antes de começar uma tarefa, combine evidências observáveis de que ela terminou. Isso evita confundir “escrevi código” com “entreguei um resultado”.

## Exemplo

Uma tela de cadastro está pronta quando:

- [ ] a pessoa consegue concluir o fluxo principal;
- [ ] campos inválidos recebem explicação compreensível;
- [ ] o servidor valida os dados;
- [ ] o dado salvo aparece onde deveria;
- [ ] o comportamento principal foi testado;
- [ ] mudanças relevantes foram documentadas.

Adapte a lista ao risco e ao contexto. Veja [[../Guias/03-Criar-Projeto|Criar Projetos]].

## Perguntas de revisão

O que é a definição de pronto? :: Evidências observáveis, combinadas antes de começar, de que a tarefa terminou.

Que confusão a definição de pronto evita? :: Confundir escrevi código com entreguei um resultado.

Quando uma tela de cadastro está pronta? :: Quando o fluxo principal funciona, campos inválidos são explicados, o servidor valida, o dado salvo aparece, o comportamento foi testado e a mudança foi documentada.

# Git e VS Code no dia a dia

## Clonar um repositório

1. Escolha uma pasta de projetos no Git Bash ou terminal.
2. Copie a URL HTTPS ou SSH do repositório.
3. Execute `git clone URL-DO-REPOSITORIO`.
4. Entre na pasta criada e leia o README antes de instalar ou alterar algo.

## Abrir no VS Code

Na pasta do projeto, `code .` abre o VS Code já naquele diretório. Se o comando não existir, instale-o pelo próprio VS Code usando a Paleta de Comandos e reabra o terminal.
